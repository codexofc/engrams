Préférences du studio (14 personnes) sur les réunions, revues en mars 2026.

- **Pas de stand-up quotidien.** Un message écrit par personne dans le canal de son équipe avant 10:00 : hier, aujourd'hui, bloqué. Trois lignes. Quelqu'un qui n'écrit rien deux jours de suite se fait demander pourquoi, gentiment.
- **Une réunion de jalon d'une heure**, le lundi après le playtest, tout le studio ([[milestone-process]]). C'est la seule réunion obligatoire.
- **Les décisions vont dans un ticket** le jour même. Une décision prise en discussion instantanée et non reportée dans un ticket n'existe pas ; on l'a appris avec le changement de vitesse du cotre discuté trois fois.
- **Jeudi après-midi sans réunion** pour tout le monde. Les revues de code se font par écrit ce jour-là aussi.
- **Une réunion a un ordre du jour écrit** dans l'invitation, sinon elle est déclinée sans que ce soit mal pris.
- **Les revues de playtest se font avec les notes d'observation à l'écran**, pas avec des slides ([[playtest-feedback-loop]]).
- **Français à l'oral**, avec les termes du glossaire ([[studio-glossary]]) tels quels ; anglais pour les identifiants même à l'oral, pour ne pas avoir deux noms pour une chose.
- **Pas de réunion pour annoncer** : une annonce est un message écrit. Une réunion sert à décider ou à regarder quelque chose ensemble.
